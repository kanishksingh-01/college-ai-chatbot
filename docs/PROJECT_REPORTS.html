INTRODUCTION :
The AI Chatbot for College is a web-based, cloud-deployed conversational assistant designed to provide instant, 24x7 guidance on academic, financial, and administrative matters. It addresses inquiries regarding admission procedures, course eligibility, detailed fee schedules, semester examination timetables, attendance regulations, placement statistics, residential hostel facilities, scholarships, and departmental faculty contacts. The architecture integrates rule-based keyword matching with typo-tolerant fuzzy fallback algorithms to interpret misspelled student queries accurately.
Each academic year, college administrative personnel expend substantial time addressing identical, high-volume repetitive student inquiries. The AI Chatbot resolves this operational bottleneck by offering an always-available digital portal where students can instantly self-serve accurate information without waiting in administrative queues. Furthermore, the application is packaged as an installable Progressive Web App (PWA) with multi-modal voice input and output.
PROBLEM STATEMENT :
Students consistently struggle to acquire prompt answers to routine college inquiries outside standard administrative working hours (10:00 AM – 5:00 PM). Administrative counters experience high congestion, leading to long student queues and placing heavy recurring burdens on college office staff.
Currently, most collegiate institutions lack a centralized, automated digital self-service platform that provides student-specific academic information (such as real-time attendance and fee dues). This absence results in communication delays, manual administrative inefficiency, and frequent unnecessary campus visits.

PROPOSED SYSTEM :
The proposed system, AI Chatbot for College, delivers an automated, intelligent conversational experience that resolves common inquiries instantly through dual-tier keyword matching and fuzzy string matching. It unifies a student self-service portal, a securely authenticated admin dashboard, chat history analytics, and continuous cloud deployment (GitHub → Render) into a cohesive architecture.
Users can interact by typing in natural language, speaking through voice input, or tapping categorized suggestion chips. For authenticated students, the backend retrieves individual academic records (attendance percentage, fee dues, CGPA score, assigned faculty mentor, and next exam date). Answers containing structured tabular data (such as semester fee structures and examination datesheets) are dynamically rendered as interactive HTML tables.
PROJECT DESCRIPTION :
AI Chatbot for College is an institutional web software application constructed to reduce administrative workloads while providing students with 24/7 academic support.
The frontend is engineered with responsive HTML5, modern CSS3 (supporting Light and Dark themes via CSS custom properties), and vanilla JavaScript. The backend is implemented in Python using the Flask WSGI microframework, interacting with a lightweight SQLite relational database. When a student enters a query, the Flask server first verifies whether the query relates to personal student records; if not, it evaluates the message against the indexed FAQ knowledge base and returns a formatted response. An admin panel enables authorized staff to curate FAQs and review student feedback without modifying code.

ADVANTAGES :

  • Administrative Workload Reduction : Offloads routine repetitive inquiries, enabling staff to focus on critical tasks.

DISADVANTAGES / LIMITATIONS :
  • Rule-Based Boundaries : Since the NLP engine uses rule-based keyword matching with fuzzy fallback, questions phrased with complex non-standard vocabulary may trigger the fallback prompt.
  • Information Currency : System accuracy depends on administrators updating the database as college rules evolve.
  • Internet Requirement : Requires active network connectivity to reach the cloud server.
  • Free Hosting Container Latency : On Render's free tier, the application may take ~30 seconds to wake up after 15 minutes of idle time.

9. Explain the data flow of your application.
When a student submits a query via text or microphone, JavaScript transmits an AJAX POST request to the Flask /chat endpoint. The backend checks if the student is authenticated and requesting personal data (e.g. "my attendance", "my cgpa"); if so, it queries the students table. Otherwise, it invokes match_query(), comparing words against the college_info table via exact and fuzzy matching. The query-response pair is logged into chat_history, and a JSON payload is returned. The frontend parses markdown and tables, renders the bubble, and plays a synthesized audio chime.

1. Define Software Testing.
Software Testing is the systematic process of evaluating an application by executing its code with test inputs and comparing actual outputs with expected specifications to detect bugs and ensure quality. In this project, testing verified that all 14 FAQ categories return accurate data, typo-tolerant fuzzy matching maps misspelled queries correctly, student authentication protects confidential records, and admin actions perform securely.
