• Project Modules :
Student Query & NLP Module – Detects keywords using exact matching combined with typo-tolerant fuzzy matching (via difflib) to answer queries across 14 categories: admission, fees, timetable, attendance, library, courses, faculty contacts, branch change, placements, hostel & mess, scholarships, clubs, emergency helplines, and campus location/transit.
Voice Interaction Module – Implements hands-free accessibility with Speech-to-Text voice input and Text-to-Speech audio readout of bot responses using native browser Web Speech APIs.
Student Login & Profile Module – Allows students to log in using their registration number (ISTU-prefixed) to receive personalized data: attendance percentage, pending fee dues, CGPA score, assigned mentor, exam dates, and complete profile summaries.
Admin Panel & Analytics Module – Provides a secure dashboard with live KPI metric cards (Total FAQs, Queries Handled, Registered Students), real-time search/filter, FAQ management, and CSV export of query logs.
Chat History & Feedback Module – Stores all student queries, bot responses, timestamps, and 👍/👎 satisfaction ratings in the database for record-keeping and future analysis.
Installable App Module – Configured as a Progressive Web App (PWA), allowing students to install it directly to their phone or laptop home screen and use it like a native app, without any app store.

INTRODUCTION :
The AI Chatbot for College is a web-based application, deployed live and publicly accessible, designed to provide instant, 24x7 answers to common student queries such as admission details, fee structure, exam timetable, attendance rules, library timings, course information, faculty contact details, branch/course change procedures, placements, hostel accommodation, scholarships, and campus facilities. The system uses rule-based keyword detection with typo-tolerant fuzzy matching to understand student questions and respond with accurate information stored in a database.
Every academic year, college administrative staff spend a significant amount of time answering the same repetitive questions from students. The AI Chatbot for College solves this problem by providing a centralized, always-available platform where students can get immediate answers without visiting the college office or waiting for staff availability. The chatbot is also configured as an installable Progressive Web App with voice input and output capabilities, so students can add it to their phone's home screen and interact using text or voice.
PROBLEM STATEMENT :
Students often struggle to get quick answers to basic college-related questions, especially outside office hours. College administrative staff are repeatedly asked the same set of questions regarding admission, fees, timetables, and attendance, which adds to their daily workload and reduces their availability for other important tasks.
There is currently no centralized, automated system in most colleges that allows students to self-serve this information at any time. This results in delays, unnecessary visits to the college office, and inefficient use of staff time.

PROPOSED SYSTEM :
The proposed system, AI Chatbot for College, is a web-based chatbot application that instantly answers common student queries using rule-based keyword matching with fuzzy, typo-tolerant fallback. It integrates a student login feature, a securely authenticated admin panel with live analytics, voice interaction, and a chat history log into a single platform, and is deployed live with a continuous deployment pipeline (GitHub to Render), so updates go live automatically.
The system allows students to type their queries in plain text, speak via microphone, or tap quick-reply category buttons, which the chatbot analyzes for relevant keywords before fetching the correct predefined answer from the database. Students who log in with their registration number receive personalized responses, such as their own attendance percentage, fee dues, CGPA score, assigned faculty mentor, or exam date, in addition to general FAQ answers. Answers containing tabular data (such as the fee structure or exam timetable) are rendered as properly formatted tables in the chat interface rather than plain text.
PROJECT DESCRIPTION :
AI Chatbot for College is a web-based chatbot application designed to reduce the workload of college administrative staff while giving students round-the-clock access to important information.
The system provides a polished chat interface built with HTML, modern CSS with Dark/Light theme switching, and JavaScript, connected to a Python Flask backend. When a student types or speaks a query, the backend matches keywords against an expanded set of 14 categories — admission, fees, timetable, attendance, library, courses, faculty, branch change, placements, hostel, scholarships, clubs, emergency helplines, and campus map — and returns the corresponding answer from the SQLite database. An admin panel allows the college staff to update this information whenever it changes and export audit logs as CSV.

SCOPE OF THE PROJECT :
The scope of the AI Chatbot for College is to provide a reliable, easy-to-use platform where students can get instant answers to common college-related questions. The system is designed for use by current students, prospective applicants, and college administrative staff across smartphones, tablets, and computers.

EXISTING SYSTEM :
In the existing system, students depend on visiting the college office, calling staff, or checking scattered notices and websites to find information about admission, fees, timetables, and other college matters. This process is time-consuming and only available during office hours.
There is no centralized digital system in most colleges that allows students to instantly self-serve this information, resulting in repeated queries to staff and unnecessary delays.

ADVANTAGES :
The AI Chatbot for College provides students with instant, 24x7 access to important information without needing to visit the college office. It reduces the repetitive workload on administrative staff by automatically handling common queries, and tolerates minor typing mistakes through fuzzy matching so students still get accurate answers.
The system features multi-modal voice interaction (Speech-to-Text and SpeechSynthesis), an accessible Dark/Light mode, and personalized student data lookup (attendance, fee balance, CGPA, and mentor). The system is easy for admins to update through a securely authenticated dashboard, requiring no coding knowledge for routine changes. The chat history feature allows the college to review commonly asked questions and export logs to CSV. The chatbot can also be installed as an app on a student's phone or laptop for quicker, native-like access. Overall, it improves student experience and administrative efficiency.
DISADVANTAGES / LIMITATIONS :
Since the chatbot relies on rule-based keyword matching and fuzzy matching rather than open-domain generative AI, queries phrased in highly unusual ways may trigger the fallback prompt. It depends on the admin keeping the database updated with accurate, current information.
The system requires an internet connection to function. On the free cloud hosting tier (Render), the application enters sleep mode after 15 minutes of inactivity and requires ~30 seconds to wake up on the first request.
